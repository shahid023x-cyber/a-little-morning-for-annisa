# A Little Morning for Annisa

This is a real interactive four-page website. All visible text, task checkboxes, buttons, page transitions, breathing activity and navigation are HTML/CSS/JavaScript elements (not a screenshot).

## Open it
Double-click `index.html` or open it in Chrome. Internet is only used for optional Google Fonts; the page structure and interactions run locally.

## GitHub Pages
Upload `index.html` to the root of a GitHub repository. Open Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. Share the URL GitHub provides.
